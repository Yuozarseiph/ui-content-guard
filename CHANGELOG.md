# Changelog

All notable project changes are documented here. This project uses Semantic Versioning.

## [1.0.0] - 2026-11-09

### Added
- Portable, instruction-first Agent Skill with discoverable YAML metadata.
- Content-boundary decision process and necessity test.
- UX writing, accessibility, Persian/RTL, design-system, form, feedback, and audit references.
- Realistic before/after scenarios including consent, destructive actions, and background processing.
- Optional host metadata, standard-library validation, and prompt-based acceptance cases.
- Installation, contribution, security, and release documentation.

### Notes
- Initial public release. No host-specific runtime or external service is required.
