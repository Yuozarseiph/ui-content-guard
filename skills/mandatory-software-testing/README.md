# Mandatory Software Testing Skill

This folder is the portable, self-contained [Agent Skills](https://agentskills.io/specification) unit. Its entry point is [`SKILL.md`](SKILL.md). Keep all files in `references/` alongside it and do not move the Skill's internal paths.

The governance baseline is [`references/00-agent-contract.md`](references/00-agent-contract.md); the test-specific references and dependency matrix are loaded as needed. The optional [`agents/openai.yaml`](agents/openai.yaml) supplies agent UI metadata.

For installation, prerequisites, supported agents, and publishing instructions, see the [repository README](../../README.md).
